# Third-party data notices and attribution

This repository contains project code and references to third-party animal-health, climate and geographic data. The project repository's MIT licence applies to the project code; it does not automatically relicense third-party data.

## WOAH / WAHIS animal-health information

Source: World Organisation for Animal Health (WOAH), World Animal Health Information System (WAHIS), public interface: https://wahis.woah.org/

The WAHIS public interface publishes official animal-health information supplied by Veterinary Services. WOAH states that public-interface data are made available for analysis, interpretation and risk-based decision-making. Cite WOAH/WAHIS and the specific report/export when displaying the data.

The quantitative extract used in this research should not be confused with a complete record of disease absence: WAHIS six-monthly reporting separates qualitative occurrence status (Part 1) from quantitative reporting for diseases present (Part 2). The project must retain this distinction.

WOAH source information: https://www.woah.org/en/what-we-do/animal-health-and-welfare/disease-data-collection/

## Copernicus Climate Change Service (C3S) / ERA5-Land

Source: Copernicus Climate Change Service, ERA5-Land hourly data from 1950 to present.  
Dataset DOI: https://doi.org/10.24381/cds.e2161bac  
Dataset page: https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land

The dataset page identifies a CC-BY licence. Cite Copernicus Climate Change Service (C3S) and the ERA5-Land dataset DOI. Document all transformations, aggregation and unit conversions applied to derived climate features.

## geoBoundaries / GRID3 Nigeria ADM1

Source: geoBoundaries Nigeria ADM1 boundary dataset.  
Dataset metadata: https://www.geoboundaries.org/api/current/gbOpen/NGA/ADM1/  
Provider: geoBoundaries; source listed in metadata: GRID3.  
Metadata reports boundary reference year 2022, 37 ADM1 units and CC BY 4.0.

Attribution to geoBoundaries is required. Link to https://www.geoboundaries.org/ on a website using the boundary data, and include geoBoundaries in the app credits/help/about section.

## Important licensing note

Always check the licence and metadata for the exact source file and version being redistributed. Do not assume that the project's MIT code licence grants rights to redistribute third-party data or that one source's licence applies to another source.
