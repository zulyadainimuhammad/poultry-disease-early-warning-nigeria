# Raw Data

This directory is reserved for source datasets exactly as obtained from external providers.

For this public repository, raw WAHIS and other third-party datasets are intentionally not committed by default. Reproducibility should be supported through documented source URLs, extraction dates, query/filter settings, file names, and checksums where appropriate.

Initial source:
- WOAH World Animal Health Information System (WAHIS)

The working WAHIS export used during the initial audit is maintained outside the public repository.
